3D Geometric Transformation Visualizer

An interactive AR/VR learning environment that transforms abstract mathematical concepts into intuitive visual experiences.

What started as a simple cube-based system evolved into a dynamic platform supporting:

  • Multiple Platonic geometries
  • Real-time transformation visualization
  • Linear algebra decomposition
  • Gesture-based interaction
  • Augmented reality projection
